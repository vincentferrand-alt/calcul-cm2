# Calcul CM2

Appli web de calcul mental pour le CM2 : HTML/CSS/JS sans étape de build, publiée par GitHub Pages, installable (PWA) et jouable hors ligne.

- Adresse : https://vincentferrand-alt.github.io/calcul-cm2/
- Tests : `node --test tests/`
- Aucune donnée personnelle dans ce dépôt public (ni prénom, ni code secret).
